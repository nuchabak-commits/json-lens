# JSON Lens v0.1

A privacy-first, browser-only JSON inspector.

## Features
- JSON validation
- Format / minify / copy / clear
- Expandable tree view
- Table view with nested-object flattening
- Search keys, values, and paths
- Click a key to get its JSONPath
- Basic JSON statistics
- Responsive UI
- No backend and no uploads

## Run
Open `index.html` directly, or serve the folder with any static web server.

Example:
```bash
python -m http.server 8080
```
Then open `http://localhost:8080`.
